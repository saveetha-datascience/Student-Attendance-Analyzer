# Student Attendance Analyzer

## Project Description

Student Attendance Analyzer is a Python-based data analysis and Streamlit dashboard project used to analyze student attendance records.

The project calculates attendance percentages, identifies students with low attendance, compares student performance, and provides subject-wise attendance analysis.

## Features

- Display student attendance data
- Calculate attendance percentage
- Show overall attendance statistics
- Analyze subject-wise attendance
- Identify the lowest and highest attendance subjects
- Identify students below 75% attendance
- Compare attendance between students
- Download individual student attendance data
- Interactive student selection

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- Jupyter Notebook

## Dataset

The project uses a CSV dataset containing:

- Student ID
- Student Name
- Department
- Subject
- Classes Held
- Classes Attended

## Attendance Calculation

Attendance Percentage is calculated using:

Attendance Percentage = (Classes Attended / Classes Held) × 100
